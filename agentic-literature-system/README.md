# Agentic Literature System

Find papers, read the evidence, and organize findings with the survey taxonomy.

**Discover → Read → Annotate → Validate → Report**

Choose the version that fits your workflow:

| | Use it when… | Get started |
| --- | --- | --- |
| **Skill** | You already use an agent with web and PDF tools. | [Install the skill](skill/README.md) |
| **Harness** | You want a Python runner with budgets, saved progress, and recovery. | [Run the harness](harness/README.md) |

```bash
git clone https://github.com/AgenticGraphics/Awesome-Agentic-Graphics.git
cd Awesome-Agentic-Graphics/agentic-literature-system
```

Both versions preserve paper identifiers, dates, supporting evidence, taxonomy labels, and coverage limits. The skill uses its host's tools; the harness uses your configured model and search service. Results can differ across models and runs.

The bundled research snapshot is dated **October 15, 2026**, with 18 taxonomy fields and 259 discussed-paper entries, including repeated placements. It is versioned separately from later survey terminology. See the [source registry](skill/references/source-registry.md) before updating it.
